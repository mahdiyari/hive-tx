Operation names

addOperation accepts every Hive operation name, and TypeScript checks the body against it. Common ones:

  • vote, comment, delete_comment, comment_options
  • transfer, transfer_to_vesting, withdraw_vesting, recurrent_transfer
  • custom_json, custom
  • delegate_vesting_shares, claim_reward_balance
  • account_update, account_update2, account_create, create_claimed_account
  • account_witness_vote, account_witness_proxy, witness_update, witness_set_properties

The full list is the Operation type in dist/index.d.mts, or src/types.ts on GitHub.
