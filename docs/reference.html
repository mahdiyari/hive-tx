Operation names

TypeScript accepts Hive operation names as the first argument of addOperation. The body type matches the name. Common names:

  • vote, comment, delete_comment, comment_options
  • transfer, transfer_to_vesting, withdraw_vesting
  • custom_json, custom
  • delegate_vesting_shares, claim_reward_balance
  • account_update, account_update2, account_create
  • account_witness_vote, account_witness_proxy
  • recurrent_transfer, witness_update, witness_set_properties

The full list is in src/types.ts.
