Use

RPC and REST calls

callRPC, callREST, and callWithQuorum send requests to Hive nodes.

callRPC

callRPC sends a JSON-RPC 2.0 request. The function returns the result. The function throws RPCError for a Hive RPC error.

import { callRPC } from 'hive-tx'

const accounts = await callRPC('condenser_api.get_accounts', [['alice']])
const props = await callRPC('condenser_api.get_dynamic_global_properties')

Parameters:

NameDefaultFunction
methodrequiredAPI method name
params[]Array or object
timeoutconfig.timeoutTimeout in milliseconds
retryconfig.retryRetry count after a network failure

If a node does not respond, the library selects the next URL in config.nodes.

Hive API names are in the Hive developer documentation.

callWithQuorum

callWithQuorum sends the same method to more than one node. The function returns a result only if that number of nodes give the same JSON.

import { callWithQuorum } from 'hive-tx'

const accounts = await callWithQuorum(
  'condenser_api.get_accounts',
  [['alice']],
  2
)

The default quorum is 2. The quorum must be less than or equal to config.nodes.length.

Note Quorum is JSON equality. Quorum is not a check of head-block lag. Do not change config.nodes during concurrent calls.

callREST

callREST calls a REST API on config.restNodes. Not all public nodes have REST APIs.

import { callREST } from 'hive-tx'

const balance = await callREST(
  'balance',
  '/accounts/{account-name}/balances',
  { 'account-name': 'alice' }
)

API names:

  • balance
  • hafah
  • hafbe
  • hivemind
  • hivesense
  • reputation
  • nft-tracker
  • hafsql
  • status

A path parameter uses {name} in the path. Other fields become query parameters. TypeScript checks path names for each API.

Stream blocks

streamBlocks yields irreversible blocks in order, with no gaps or duplicates. Hive blocks become irreversible within seconds, so the stream is close to real time.

import { streamBlocks } from 'hive-tx'

for await (const block of streamBlocks()) {
  for (const tx of block.transactions) {
    for (const [name, body] of tx.operations) {
      if (name === 'transfer') {
        console.log(block.block_num, tx.transaction_id, body.from, body.to, body.amount)
      }
    }
  }
}
OptionDefaultEffect
fromlast irreversible blockFirst block to yield
tononeLast block to yield; the stream ends after it

Past blocks are fetched 20 per request. Once caught up, the stream polls every second. break stops the stream. If every node fails, the stream throws. Save block.block_num and resume with from: savedNum + 1.

Stream block numbers

streamBlockNumbers yields irreversible block numbers the same way, without fetching the blocks. It takes from and to like streamBlocks.

import { streamBlockNumbers } from 'hive-tx'

for await (const num of streamBlockNumbers()) {
  console.log(num)
}

Stream operations

streamOperations yields every operation of irreversible blocks in chain order, virtual operations included, like get_ops_in_block. Virtual operations are created by the chain, such as rewards, order fills, and interest. Pass only_virtual: true to get only those.

import { streamOperations } from 'hive-tx'

for await (const { block, trx_id, op } of streamOperations()) {
  if (op[0] === 'transfer') console.log(block, trx_id, op[1].from, op[1].amount)
  if (op[0] === 'producer_reward') console.log(block, op[1].producer)
}

It takes from and to like streamBlocks, plus only_virtual (default false). Each item has block, trx_id, trx_in_block, op_in_trx, virtual_op, timestamp, and op. To resume, pass from as the last block you fully handled plus one.
