Use

RPC and REST calls

callRPC, callREST, and callWithQuorum send requests to Hive nodes. Optional healthchecks and a short cache sit on that same path.

callRPC

callRPC sends a JSON-RPC 2.0 request. The function returns the result. The function throws RPCError for a Hive RPC error.

import { callRPC } from 'hive-tx'

const accounts = await callRPC('condenser_api.get_accounts', [['alice']])
const props = await callRPC('condenser_api.get_dynamic_global_properties')

Parameters:

NameDefaultFunction
methodrequiredAPI method name
params[]Array or object
timeoutconfig.timeoutTimeout in milliseconds
retryconfig.retryRetry count after a network failure
optionsomit{ cacheTtl } overrides the local cache for this call. 0 skips the cache.

If a node does not respond, the library selects the next URL in config.nodes.

Dynamic global properties are cached in memory for config.cacheTtl milliseconds. The default list is config.cacheMethods. clearCallCache() drops the stored results. Add a method name to config.cacheMethods to cache another read-only call. Do not add broadcast methods.

Hive API names are in the Hive developer documentation.

Node healthchecks

Healthchecks are off until config.healthchecks lists one or more of hived, hivemind, and hafah. Each value is optional. callRPC, callREST, and callWithQuorum then skip nodes that fail the selected probes. The probes use the same JSON-RPC client as callRPC.

  • hived calls condenser_api.get_dynamic_global_properties. The head block time must be within config.healthcheckMaxLag milliseconds of now.
  • hivemind calls condenser_api.get_follow_count for hiveio.
  • hafah calls condenser_api.get_account_history for hiveio and requires one operation.
import { checkNode, checkNodes, config, getNodeHealth, stopNodeHealthcheck } from 'hive-tx'

config.healthchecks = ['hived', 'hivemind']
config.healthcheckInterval = 30_000

const report = await checkNodes()
const one = await checkNode('https://api.hive.blog', ['hafah'])
console.log(report, one)
stopNodeHealthcheck()

Results are reused for config.healthcheckInterval milliseconds. A positive interval also starts a background recheck. 0 checks on each call and does not start a timer. startNodeHealthcheck() and stopNodeHealthcheck() control that timer. clearNodeHealth() drops stored results.

A node that fails a network call is marked unhealthy until the next refresh. If every node fails the selected checks, the call still tries the node list.

callWithQuorum

callWithQuorum sends the same method to more than one node. The function returns a result only if that number of nodes give the same JSON.

import { callWithQuorum } from 'hive-tx'

const accounts = await callWithQuorum(
  'condenser_api.get_accounts',
  [['alice']],
  2
)

The default quorum is 2. The quorum must be less than or equal to config.nodes.length.

Note Quorum is JSON equality. Quorum is not a check of head-block lag. Do not change config.nodes during concurrent calls.

callREST

callREST calls a REST API on config.restNodes. Not all public nodes have REST APIs.

import { callREST } from 'hive-tx'

const balance = await callREST(
  'balance',
  '/accounts/{account-name}/balances',
  { 'account-name': 'alice' }
)

API names:

  • balance
  • hafah
  • hafbe
  • hivemind
  • hivesense
  • reputation
  • nft-tracker
  • hafsql
  • status

A path parameter uses {name} in the path. Other fields become query parameters. TypeScript checks path names for each API.
