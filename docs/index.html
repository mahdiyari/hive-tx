Overview

hive-tx documentation

hive-tx is a TypeScript library for the Hive blockchain. The library creates transactions, signs data, and calls Hive APIs.

Install

Add the package. Use Node.js 20 or later.

Quick start

Create one vote transaction and broadcast it.

Examples

Transfers, comments, memos, RPC, keys, and more.

API reference

Classes, functions, and types.

What the library does

hive-tx does this work:

  • Build Hive operations with TypeScript types.
  • Sign operations with secp256k1 keys.
  • Broadcast signed transactions.
  • Call JSON-RPC methods and REST endpoints.
  • Encrypt memos and decrypt memos.

The library runs in Node.js, in a browser, and in a serverless runtime. The package includes ESM and CommonJS builds. Crypto code is inside the build. The package has no runtime npm dependencies.

Requirements

  • Node.js 20 or later, or a browser that supports ES2024 and fetch.
  • A Hive account and the correct private key for each operation.
