Overview

hive-tx documentation

hive-tx is a lightweight TypeScript SDK for the Hive blockchain. It builds, signs, and broadcasts transactions, calls Hive APIs, and streams the chain.

Install

Node.js 20+, browsers, workers, and serverless runtimes.

API reference

Every export and its signature.

What it does

  • Builds operations with a TypeScript type per operation, then signs and broadcasts them.
  • Calls JSON-RPC with node failover, batch requests, and quorum calls that cross-check nodes.
  • Calls typed REST APIs: balance, hafah, hafbe, hivemind, and more.
  • Streams irreversible blocks and operations, virtual ones included, with no gaps or duplicates.
  • Computes voting mana, RC, Hive Power, vote value, APR, account value, and reputation.
  • Builds follow, mute, reblog, and community operations, permlinks, and account keys.
  • Creates keys, verifies signatures, and encrypts memos by public key or account name.

It runs in Node.js, browsers, workers, and serverless runtimes. The package ships ESM and CommonJS builds and has no runtime dependencies: the crypto code is bundled.

Requirements

  • Node.js 20 or later, or a browser with ES2024 and fetch.
  • A Hive account and the right private key for each operation.
