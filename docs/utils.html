Use

Utilities

The utils object has stake and mana math, vote values, reputation, permlinks, name validation, history filters, and witness properties.

The stake, mana, and vote helpers are async and fetch what they need: account, global properties, reward fund, and price. Fetched data is cached for 2 seconds and shared by concurrent calls, so calling several helpers in a row costs one request per kind of data. Results are JavaScript numbers, accurate for display and estimates.

Voting power and mana

import { utils } from 'hive-tx'

await utils.getVotingMana('alice')      // { current, max, percentage }
await utils.getDownvoteMana('alice')
await utils.getRCMana('alice')
await utils.getEffectiveVests('alice')  // own + received - delegated - this week's power down

Instead of a name, you can pass an account object you already have, from condenser_api.get_accounts or database_api.find_accounts (for getRCMana, from rc_api.find_rc_accounts). That skips the request.

Mana is regenerated to now; pass a time in milliseconds as the last argument to compute it at another time. Mana refills from 0 to 100% in 5 days. Downvote mana is 25% of voting mana.

Hive Power

await utils.vestsToHP('1000.000000 VESTS')  // number of HIVE
await utils.hpToVests(100)                  // number of VESTS
utils.parseAsset('1.000 HIVE')              // { amount: 1, symbol: 'HIVE' }

parseAsset also reads the { amount, precision, nai } format of database_api.

Vote value

await utils.getVoteValue('alice')         // HBD, 100% vote
await utils.getVoteValue('alice', 5000)   // 50% vote
await utils.getVoteRShares('alice')       // rshares
await utils.rsharesToHBD(rshares)         // HBD of any rshares

Weight is -10000 to 10000. Since HF28, vote strength depends on stake and weight only. Current mana limits how many votes an account can cast, not how strong each vote is. The value combines author and curation rewards.

Reputation

utils.formatReputation('225722985673795')  // 73.18

Converts raw reputation, as returned by condenser_api.get_account_reputations, to the usual score. Use Math.floor for the whole number most frontends show.

createPermlink

utils.createPermlink('Hello World!')  // 'hello-world-3f9a1c0b7e2d'
utils.createPermlink()                // '3f9a1c0b7e2d', for replies

Makes a valid permlink from a title, with a random suffix so titles can repeat.

validateUsername

The function returns null if the name is valid. The function returns an error string if the name is not valid.

import { utils } from 'hive-tx'

const error = utils.validateUsername('alice')
if (error) {
  console.log(error)
}

makeBitMaskFilter

Use the filter with condenser_api.get_account_history.

const filter = utils.makeBitMaskFilter([
  utils.operations.transfer,
  utils.operations.vote,
  utils.operations.comment
])
const history = await callRPC('condenser_api.get_account_history', [
  'alice',
  -1,
  100,
  ...filter
])

utils.operations maps operation names to numeric ids. Example: vote is 0. transfer is 2.

buildWitnessSetProperties

This helper is required for witness_set_properties. The helper serializes property values to hex.

const operation = utils.buildWitnessSetProperties('mywitness', {
  key: 'STM1111111111111111111111111111111114T1Anm',
  account_creation_fee: '0.000 HIVE',
  maximum_block_size: 65536,
  url: 'https://example.com'
})
const tx = new Transaction()
await tx.addOperation(operation[0], operation[1])

The key field is required. The field is the current signing public key.
